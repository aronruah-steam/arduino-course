PART 01 · 電學基本知識與安全規範

掌握電壓、電流與電阻，看懂麵包板如何讓電路通起來

在接上任何電子元件之前，先搞懂電路的三大基本物理量與歐姆定律，就能避開燒毀 LED 或晶片短路的常見新手意外。

V · 伏特 (Volt)

電壓 Voltage

好比水塔的水壓差，推動電子在導線中流動的驅動力。Arduino Uno 的數位腳位高電位 (HIGH) 是 5V，低電位 (LOW) 是 0V（接地 GND）。

I · 安培 / 毫安 (mA)

電流 Current

每秒通過導線截面的電子流量。一般 5mm LED 安全工作電流約 10–20 mA；Arduino Uno 單一腳位建議最大輸出為 20 mA（極限 40 mA）。

R · 歐姆 (Ω)

電阻 Resistance

阻礙電流通過的能力，用來「限流」保護元件或進行分壓。實驗最常使用 220Ω（紅紅棕金）保護 LED，以及 10kΩ（棕黑橙金）搭配按鍵與光敏電阻。

核心公式

歐姆定律 V = I × R

電流與電壓成正比、與電阻成反比。若 5V 電源接紅光 LED（壓降約 2V）並串聯 220Ω 電阻，電流約為 (5 - 2) / 220 = 13.6 mA，安全又夠亮！

開路 vs 短路：中學實驗室安全守則

開路 Open Circuit

電路沒有形成完整迴路（例如跳線鬆脫、GND 沒接好、LED 長短腳接反）。雖然不會燒毀元件，但電路完全不會動作。

短路 Short Circuit

正極（5V）未經負載直接連回負極（GND），電阻趨近 0Ω 導致電流瞬間暴增，會讓導線發燙、電源重置甚至燒毀電腦 USB 埠！

接線鐵則

修改任何接線前，務必先拔除 USB 傳輸線！確認紅色正極與黑色接地未直接相連後再通電。

互動實驗 1B：麵包板 (Breadboard) 內部導通透視模擬器

點選麵包板上不同孔位區域，透視面板底下金屬銅片的實際導通方向！

水平整排導通

上下兩側電源軌（+ 正極 / - 負極）

標示紅線（+）與藍線（-）的兩排孔洞，底部的金屬銅片是「水平一整排連通」的。通常從 Arduino 的 5V 接一條線到紅色軌，GND 接到藍色軌，整條軌道就能分接給所有元件使用！

提示：少數加長型麵包板正中間會斷開，需視紅藍線是否連續

核心觀念：
setup() 在通電或按下 Reset 後只執行一次；接著進入 loop()，只要不斷電就會每秒數千次不斷循環重複！

void setup() { pinMode(13, OUTPUT); }

2
digitalWrite(13, HIGH);
進入 loop()：送出 5V 高電位，點亮 LED
3
delay(1000);
暫停等待 1000 毫秒（1 秒鐘）
4
digitalWrite(13, LOW);
改送出 0V 低電位，熄滅 LED
5
delay(1000); // 回到第 2 步無限重複
再等 1 秒後回到 loop() 開頭繼續執行

Arduino IDE 開發四步驟

步驟 操作與目的
1. 選板子 工具 → 開發板 → 選擇 Arduino Uno
2. 選序列埠 工具 → 序列埠 (Port) → 選取電腦偵測到的 COM 或 usbmodem
